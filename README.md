# MARVEL Word Guessing Game

A fun twist on the classic Hangman game, featuring Marvel-themed words. Guess the word before you run out of lives,
which are represented by the letters "MARVEL." The game gives you a free hint by revealing one letter to help you along the way.

## Features:
- Randomly selects a Marvel-themed word (e.g., characters, locations, and more).
- You have 6 tries to guess the word.
- Wrong guesses remove one letter from "MARVEL" as your lives.
- The game includes a hint by revealing one letter at the start.

## How to Run:
1. Make sure Python (version 3.x) is installed.
2. Download the `marvel.py` file.
3. Open your terminal or command prompt and start playing
